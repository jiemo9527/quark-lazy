# 夸克懒得点

多网盘增强油猴脚本：RPC 下载、复制 Bash 下载命令、分享来源红橙名单、保存日志与 WebDAV 同步。

## 安装

1. 在浏览器安装 Tampermonkey 等用户脚本管理器。
2. [点击安装脚本](https://raw.githubusercontent.com/jiemo9527/quark-lazy/main/%E5%A4%B8%E5%85%8B%E6%87%92%E5%BE%97%E7%82%B9.user.js)。
3. 打开支持的网盘，通过脚本菜单或页面工具栏的「设置」配置功能。

项目主页为本仓库。脚本的 `@downloadURL` / `@updateURL` 仍保留 Greasy Fork 地址，未改变现有自动更新渠道。

## 功能

- 支持夸克、115、UC、百度、天翼、迅雷、139、123、光鸭的 RPC 下载适配。
- 独立配置 RPC 服务器、下载目录及绑定关系；下载失败项支持重试。
- 复制可导入 Motrix 的 Bash 下载命令。
- 分享者红名单（屏蔽）与橙名单（警告），按网盘隔离；115 使用可信账号 ID。
- 日志中心包含保存记录、下载记录、失败记录，支持网盘筛选、搜索、复制、勾选删除及清空。
- 保存记录操作列显示「已屏蔽」「已警告」，切换名单后即时更新。
- 「刷新日志」只重新读取日志内容，不刷新网盘页面。
- 夸克原生按钮手动保存成功后也记录，包括临时允许的屏蔽分享者。
- 可选 WebDAV 数据备份/恢复；WebDAV 账号本身不参与备份。

> RPC 接收成功不代表文件已下载完成。各网盘功能受站点接口、登录状态及权限影响；自动化测试不等同于真实网盘转存测试。

## 使用与隐私

- 自动转存、自动全选、文件夹递归发送等功能可在各站点专属设置中调整。
- 115 影巢一键转存可能自动消耗资源解锁积分，使用前请确认资源说明。
- Bash 命令和失败记录可能包含直链、Cookie、请求头等登录信息，请勿公开分享。
- WebDAV 上传的数据可能含网盘令牌、失败下载地址和请求头，请使用可信的私有存储。
- 仓库仅存放脚本、测试和项目文档，不包含个人脚本存储、日志、WebDAV 凭据或 RPC 实际配置。

## 开发与测试

需要 Node.js 24 或更高版本。

```bash
npm ci
node --check 夸克懒得点.user.js
npm test
```

测试通过 Node 内置测试运行器、VM 与 jsdom 覆盖分享者识别、转存流程、日志交互、下载命令及文件筛选。提交后 GitHub Actions 运行相同检查。
